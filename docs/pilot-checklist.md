# 10人试运营清单

## 上线前

- [ ] 两个 SQL migration 已执行。
- [ ] Supabase 匿名登录已开启。
- [ ] Turnstile 已配置 `localhost` 和正式域名。
- [ ] GitHub Actions 三个环境变量已配置。
- [ ] 管理员能在 Supabase 控制台查看私有图片。
- [ ] 用自己的手机完整提交一条饭评并审核通过。
- [ ] 用另一台设备点赞和评论，确认评论审核后才显示。

## 邀请对象

尽量覆盖不同使用习惯：

- [ ] 3位经常在一楼吃饭的同学
- [ ] 3位经常在二楼吃饭的同学
- [ ] 2位经常在三楼吃饭的同学
- [ ] 2位平时很少逛校园网站的同学

## 每位同学要完成

- [ ] 找到自己常去的楼层。
- [ ] 打开一条饭评详情。
- [ ] 点赞一次，再取消一次。
- [ ] 上传一条真实饭评。
- [ ] 提交一条评论。
- [ ] 把一条饭评链接分享给另一位同学。

1. 第一次打开时，你是否立刻知道这个网站是做什么的？

## 是否进入第二版

满足以下条件再继续扩功能：

- 至少8人能独立完成浏览和点赞。
- 至少5人愿意提交真实照片。
- 没有出现待审核内容泄漏。
- 没有重复点赞或连续刷投稿。
- 至少3人表示一周内愿意再次打开。

第二版功能只从试用反馈中选择，不凭感觉堆功能。
